fala-gringoHTML · JS · PWA

Fala Gringo

Textbooks teach European Portuguese. I wanted to drill the spoken Brazilian kind, every day, without an account.

A free, offline-first site: you see English, you type the Portuguese. Verbs across five tenses, nouns with their gender, everyday expressions, full sentences, and seven daily cards you can share. No login, no tracking. It later grew sister sites for Brazilians learning English and Norwegian.

falagringo.com · source

autotennisPython · No LLMs

Autotennis

Drop-in tennis and padel sessions at the university club had to be booked by hand, and I wanted to be on court more often.

A small Python service that books the sessions for me. Built entirely without LLMs; it did exactly what I needed it to do.

github.com/henrikhestnes/Autotennis

cuda-matmulCUDA · Pybind11 · No LLMs

CUDA matrix multiplication from Python

NumPy makes a matrix multiply one character long. I wanted to know what the GPU actually does underneath, and to call my own version from Python.

Two CUDA kernels written by hand: one reads straight from global memory, the other stages 32×32 tiles in shared memory. Pybind11 exposes them to Python as plain functions on NumPy arrays, and any matrix size works, not just multiples of the tile. A small script races them against a C++ loop, NumPy and pure Python, and checks every result. Built entirely without LLMs.

github.com/henrikhestnes/CUDA-Pybind11-matrix-multiplication
